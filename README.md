## 🐶 Project Overview

A fully integrated pet services website for **Belinda and Melissa’s** U.S.-based business. This platform, developed using **SOFTR**, allows customers to book pet care services and enables real-time backend operations powered by **Monday.com**. It supports **dog daycare, boarding, grooming**, and more with automated workflows and staff management.

---

## ✨ Key Features

### 🐕 Customer-Facing

* **Service Pages**: Info on Dog Daycare, Boarding (Dog/Cat), Grooming, Self-Serve Bathing, Ordure Removal
* **Reservations**: Online forms for booking services
* **User Accounts**: Secure login and password management
* **Responsive UI**: Mobile-ready experience

### 🛠️ Backend Operations

* **Staff Management**: Clock-in/out via portal
* **Live Sync**: Auto data updates in Monday.com
* **Automations**: Triggered actions via Make.com workflows

---

## 💡 How It Works

### 🧩 User Journey Automation

1. Customer submits service request on Softr site
2. Data flows to Monday.com in real-time
3. Staff alerted automatically
4. Customer receives confirmation
5. Service is scheduled and monitored

### 👥 Employee Workflow Automation

1. Staff clocks in/out via Softr
2. Time logs are auto-recorded in Monday.com
3. Payroll data calculated from entries
4. Reports generated for management
