# Pet Services Platform

## Project Overview
This project is a comprehensive pet services website built using SOFTR, a powerful no-code frontend platform. The platform serves as the digital presence for a pet services business owned by Belinda and Melissa in the United States. The website offers various pet care services including dog daycare, boarding for dogs and cats, grooming, and more, while integrating seamlessly with Monday.com for backend data management and automations.

## Key Features

### Customer-Facing Features
- **Service Information Pages**: Detailed pages for each service offering:
  - Dog Daycare
  - Dog Boarding
  - Cat Boarding
  - Grooming
  - Self-Serve Bathing
  - Ordure Removal
- **Reservation System**: Online forms for service bookings
- **User Accounts**: Personal profiles for returning customers
- **Authentication**: Secure sign-in, password reset, and account recovery

### Business Operations Features
- **Employee Management**: Clock-in/clock-out tracking system
- **Real-Time Data Storage**: All customer and employee data automatically synced to Monday.com
- **Workflow Automation**: Custom scenarios built with Make.com (formerly Integromat) to automate business processes

## Technical Implementation

### Frontend Development
- **Platform**: Built using SOFTR's drag-and-drop interface
- **Responsive Design**: Works seamlessly across desktop and mobile devices
- **Custom Components**: Tailored UI elements designed for the pet services industry

### Backend Integration
- **Data Storage**: Monday.com serves as the primary database
- **API Connections**: Seamless integration between SOFTR frontend and Monday.com backend
- **Automation Platform**: Make.com used to create custom automation workflows

### User Journey Automation
1. Customer fills out service request form on the website
2. Data is instantly captured in Monday.com 
3. Relevant staff are notified
4. Customer receives confirmation
5. Service is scheduled and tracked through completion

### Employee Operations Automation
1. Staff members clock in/out through dedicated portal
2. Working hours are automatically recorded in Monday.com
3. Payroll data is generated based on logged hours
4. Management receives reports on staffing levels and service delivery
